Этот навык помогает быстро оценить текущее состояние фронтенд-проекта и предложить следующие шаги для локальной разработки.

## Что делает навык
- читает `package.json`, `README.md` и конфигурационные файлы проекта
- определяет установлен ли пакетный менеджер и есть ли `node_modules`
- проверяет основные скрипты `dev`, `build`, `lint`, `preview`
- собирает рекомендации по установке зависимостей и запуску

## Когда использовать
- при первом знакомстве с проектом
- перед запуском локальной разработки
- для подготовки краткого отчёта о готовности репозитория

## Использование
1. Открой рабочее пространство проекта.
2. Запусти навык с запросом, например:
   - "Проанализируй проект и скажи, что нужно для запуска"
   - "Проверь, готов ли репозиторий к разработке"
3. Получи список найденных файлов, проблем и рекомендаций.

## Примеры запросов
- "Проверь setup проекта Speakly и скажи, какие команды запускать"
- "Какие файлы конфигурации есть, и какие зависимости нужно установить?"
- "Проанализируй package.json и предложи план локального запуска"

## Критерии завершения
- найден `package.json` с основными скриптами
- проверен доступный пакетный менеджер (`npm`, `yarn`, `pnpm`)
- определено состояние зависимостей (`node_modules`/lock-файл)
- сформирован понятный план действий
